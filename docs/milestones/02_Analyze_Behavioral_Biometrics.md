# Milestone 2 — Analyze Behavioral Biometrics

## Selected Signals
- Total typing duration
- Average interval between password keystrokes
- Backspace count
- Mouse travel distance
- Average mouse speed
- Login hour

## Why these features?
They can be captured in a normal browser without specialized hardware and converted into numeric inputs for a simple machine-learning classifier.

## Limitations
Typing/mouse behavior can change due to keyboard type, touchpad/mouse, fatigue, stress, environment, injury, or deliberate behavior changes.
