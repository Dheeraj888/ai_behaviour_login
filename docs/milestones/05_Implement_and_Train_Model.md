# Milestone 5 — Implement and Train Model

## Implementation
The prototype uses Logistic Regression. Legitimate baseline samples are collected from successful logins. For demonstration only, perturbed synthetic samples create an anomalous negative class. Features are standardized before training.

## Trust Score
`P(legitimate behavior) × 100`

Default decision threshold in this prototype: **70**.
